# Setup and troubleshooting

## Connect

1. Open Nuvio Re-Shaped on the same TV.
2. Open **Add-ons → Manage from phone (QR)**.
3. Keep the QR / phone-management screen open.
4. Switch to Nuvio TV Relay and select **Connect**.
5. Wait for the catalog library and synchronization to finish.

## If catalogs do not appear

- Confirm both apps are installed on the same TV.
- Make sure the QR / phone-management screen is still open while connecting.
- Confirm the catalog source is supported by the current build.
- Restart Nuvio TV Relay and retry.
- When reporting a bug, include TV model, OS version, Nuvio Re-Shaped version, and steps to reproduce. Remove tokens, private manifest URLs, and account data from logs.

## What this app does not do

- It does not replace or patch Nuvio Re-Shaped.
- It does not play streams or resolve playable stream URLs.
- It does not transcode video.
- It cannot guarantee that every launcher displays Watch Next/recommendation items.
